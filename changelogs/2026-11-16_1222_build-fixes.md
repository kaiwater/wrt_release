# 2026-11-16 — 构建兼容性修复与 openssh-client 最终范围

## 1. golang1.27/host 依赖名不一致

部分 `packages` feed 已经写成 `golang1.27/host`，但同一棵 feed 里的 Go 包名仍是
`golang`，没有 `golang1.27` 源包。结果是 `tailscale`、`cloudflared`、`telegraf`
在扫描阶段直接失败。

新增 `fix_golang_versioned_build_deps()`：

- 仅在确认不存在 `feeds/packages/lang/golang1.27` 时生效
- 把 `golang1.27/host` 回退为 `golang/host`
- 不会影响以后真正提供 `golang1.27` 的 feed

## 2. dockerd 嵌套可执行文件

dockerd 29.x 的 `hack/make/binary-daemon` 会无条件复制：

```text
containerd containerd-shim-runc-v2 ctr runc
docker-init rootlesskit dockerd-rootless.sh dockerd-rootless-setuptool.sh
```

宿主只提供其中一部分，`command -v` 为空时 `cp` 失败，dockerd 编译中断。

新增补丁：

```text
wrt_core/patches/dockerd-skip-missing-nested-executables.patch
```

只复制实际存在的工具，缺失项跳过。

## 3. openssh-client 最终范围

`compile_base.config` 恢复全局启用：

```text
CONFIG_PACKAGE_openssh-client=y
```

之前的“仅限三个型号”提交已撤回。当前所有使用 `compile_base` 的机型都包含
openssh-client，RAX 独立构建仓库原本已包含。

体积影响以 `10.6_p1-r2` 实测：

- 安装后 rootfs 约 +1.0 MiB
- squashfs 镜像约 +0.35 MiB
- ext4 镜像约 +1.0 MiB

## 验证

2026-11-16 在 QNAP iSCSI 构建环境中完成：

- CS-02（LibWrt 25.12-nss）
- BE12 Pro（chasey 25.12-dev-wifi7）
- RAX3000M / RAX3000Me / WR30U（chasey 25.12）

三者 manifest 均包含：

```text
dropbear 2025.89-r3
openssh-client 10.6_p1-r2
```

RAX 额外包含 `coreutils-nohup`，以及 OpenClash、PassWall、diskman、ksmbd、
sing-box、geoview。
