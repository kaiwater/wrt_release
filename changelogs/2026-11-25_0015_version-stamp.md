# 2026-11-25 — 版本号尾部追加构建时间与分支

## 格式

`DISTRIB_DESCRIPTION` 保持原样，尾部追加：

```text
<YYYYMMDD HHMMSS> - <分支> <commit>
```

示例：

```text
LibWrt 25.12-SNAPSHOT r38340-000a4e74b1 20261124 210918 - LibWrt 000a4e74b17e
ImmortalWrt 25.12-SNAPSHOT r0-458d2f7 20261125 001500 - chasey 458d2f7e9295
```

分支名按源码仓库映射：

```text
LiBwrt/LibWrt        → LibWrt
chasey-dev/...       → chasey
VIKINGYFY/...        → VIKINGYFY
immortalwrt/...      → ImmortalWrt
```

## 实现

`write_release_identity()` 增加 `BUILD_STAMP` 和 `BUILD_BRANCH`，写入
`/etc/wrt_release`；`/etc/uci-defaults/98-wrt-release` 在首次启动时改写
`/etc/openwrt_release` 的 `DISTRIB_DESCRIPTION`（重复执行不会重复追加）。

`ubus call system board` 和 LuCI 的固件版本会直接显示新的字符串。

## 范围

- 本仓库（LibWrt / VIKINGYFY / chasey wifi7）
- `kaiwater/immortalwrt-mt798x-build` 的 `scripts/stamp-version.sh` 同步实现，
  通过 `files/etc/wrt_release` + uci-defaults 生效；`VERSION_CODE` 简化为
  `r0-<short>`，日期改由尾部后缀提供

## 生效方式

下次构建生效。今天（11-24）已产出的固件保持原样，不重编。
