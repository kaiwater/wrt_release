# 2026-11-06 15:41 — BE12 Pro 去掉剩余存储工具

## 背景

BE12 Pro 只有 SPI-NAND + UBI，`/sys/block` 里仅 `loop* / mtdblock* / ubiblock0_0 / zram0`，没有 USB、eMMC 或 NVMe。

之前的 `tenda_be12_pro_minimal` 片段只关了：

```text
luci-app-diskman
smartmontools-drivedb
```

但 `compile_base.config` 里还有四个存储相关包会带进镜像：

```text
sgdisk
resize2fs
kmod-fs-exfat
kmod-fs-vfat
```

对纯 UBI 设备没有实际用途。

## 变更

`wrt_core/deconfig/fragments/tenda_be12_pro_minimal.config` 增加：

```text
# CONFIG_PACKAGE_sgdisk is not set
# CONFIG_PACKAGE_resize2fs is not set
# CONFIG_PACKAGE_kmod-fs-exfat is not set
# CONFIG_PACKAGE_kmod-fs-vfat is not set
```

只作用于 `tenda_be12_pro_immwrt`，其他机型不受影响。

## 验证

合并后的配置确认：

```text
CONFIG_PACKAGE_luci-app-diskman       = n
CONFIG_PACKAGE_smartmontools-drivedb  = n
CONFIG_PACKAGE_sgdisk                 = n
CONFIG_PACKAGE_resize2fs              = n
CONFIG_PACKAGE_kmod-fs-exfat          = n
CONFIG_PACKAGE_kmod-fs-vfat           = n
CONFIG_PACKAGE_sing-box               = y
```

`config_preview` 通过，片段顺序为 `proxy,light_apps,tenda_be12_pro_minimal`。

## 预期收益

| 包 | 安装大小 |
|---|---:|
| `sgdisk` | 约 72 KiB |
| `resize2fs` | 约 40 KiB |
| `kmod-fs-exfat` + `kmod-fs-vfat` | 约 150 KiB |

未压缩合计约 260 KiB，编译后以实际镜像为准。
