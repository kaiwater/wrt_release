# 2026-11-06 12:01 — AP8220 / AX6600 / BE12 Pro 精简 app（去 iStore、lucky、xray）

## 背景

三台设备的空间压力来自同一组组件：

| 组件 | 未压缩体积 | 位置 |
|---|---:|---|
| `xray`（PassWall 第二套内核） | 29.8 MB | rootfs |
| `lucky` 预编译二进制 | 14.3 MB | rootfs |
| `quickstart`（iStore 组件） | 10.4 MB | rootfs |
| `luci-app-istorex` | 4.8 MB | rootfs |
| PassWall 规则库（geoip/geosite/chnlist） | 29 MB 逻辑 | overlay |

BE12 Pro 之前已经去掉 iStoreX、xray、diskman，但仍保留 lucky；AP8220 和 AX6600 则四样都在。

lucky 的 LuCI 包 `luci-app-lucky` 硬依赖 `lucky`，而 `lucky` 是构建时从上游 release 下载的预编译二进制（`PKG_SOURCE_URL` 指向 `gdy666/lucky` 的 GitHub Release），不存在“只装 LuCI 页面、不装二进制”的干净做法，所以最小化等同于两个包都不装。

## 变更

新增通用片段：

```text
wrt_core/deconfig/fragments/light_apps.config
```

内容：

```text
# CONFIG_PACKAGE_luci-app-istorex is not set
# CONFIG_PACKAGE_luci-app-store is not set
# CONFIG_PACKAGE_luci-app-quickstart is not set
# CONFIG_PACKAGE_quickstart is not set
# CONFIG_PACKAGE_luci-app-lucky is not set
# CONFIG_PACKAGE_lucky is not set
# CONFIG_PACKAGE_luci-app-passwall_INCLUDE_Xray is not set
# CONFIG_PACKAGE_xray-core is not set
CONFIG_PACKAGE_luci-app-passwall_INCLUDE_SingBox=y
```

应用范围（三个型号）：

| 设备 | 片段顺序 |
|---|---|
| AP8220 | `nss,samba_ksmbd,usb_storage,proxy,light_apps` |
| AX6600（CS-02） | `nss,samba_ksmbd,usb_storage,docker_deps,proxy,light_apps` |
| BE12 Pro | `proxy,light_apps,tenda_be12_pro_minimal` |

`tenda_be12_pro_minimal` 只保留设备特有的磁盘阵列相关项：

```text
# CONFIG_PACKAGE_luci-app-diskman is not set
# CONFIG_PACKAGE_smartmontools-drivedb is not set
```

iStore / xray / lucky 的移除统一由 `light_apps` 负责，避免两个片段重复维护。

## 影响

- 不再安装 `luci-app-istorex`，同时连带去掉 `luci-app-store`、`luci-app-quickstart`、`quickstart`、`luci-lib-taskd`
- 不再安装 `lucky` 与 `luci-app-lucky`
- 不再安装 `xray-core`，PassWall 只保留 `sing-box`
- 需要 xray 时可在设备上执行 `apk add xray-core`，不影响已有 sing-box 配置
- 其他机型（含 `libwrt_all` / `immwrt_all` 里的其他设备）不受影响

预计未压缩节省约 60 MB；squashfs 压缩后的实际镜像缩减需要编译后确认。

## 验证

- 三个型号的 `config_preview` 均通过，片段顺序正确
- 合并后的配置中目标符号全部为 `n`，`sing-box` 与 `INCLUDE_SingBox` 为 `y`
- `build.sh` / 模块脚本未改动，`update_lucky` 与 `fix_quickstart` 本身有存在性判断，包不选时不会报错

## 现场核对

抽查了三台设备：

| 设备 | 现状 |
|---|---|
| AP8220（新固件） | iStore / quickstart / xray / lucky 全在，rootfs 70.3 MiB，overlay 8.7/39.5 MiB |
| AX6600 | 同上，rootfs 6.12.112 构建，overlay 有 PassWall 规则库 |
| BE12 Pro | 已无 iStore / quickstart / xray / diskman，但仍有 lucky 14.3 MB 与 geoview 7.7 MB；overlay 11.4/25 MiB，主要是规则库和 OAF 图标 |

三台设备的 overlay 大头都是 PassWall 规则库，BE12 Pro 另外多一个 1.4 MB 的 WiFi `e2p` 备份。
