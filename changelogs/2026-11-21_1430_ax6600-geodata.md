# 2026-11-21 — AX6600 单独启用 geoip / geosite 内置

## 背景

AX6600（CS-02）rootfs 分区 87.3 MB，当前 squashfs 54.5 MB，overlay 1.9 GB
只用了约 140 MB，空间充足。之前 `light_apps` 为了省空间，把 v2ray geo 数据
从所有机型移出 rootfs，改由 PassWall 运行期下载到 overlay。

## 变更

新增 fragment `wrt_core/deconfig/fragments/geo_full.config`：

```text
CONFIG_PACKAGE_luci-app-passwall_INCLUDE_V2ray_Geodata=y
CONFIG_PACKAGE_v2ray-geoip=y
CONFIG_PACKAGE_v2ray-geosite=y
```

只有 `jdcloud_ipq60xx_libwrt` 的 fragment 列表追加了它，且排在 `light_apps`
之后：

```text
nss,samba_ksmbd,wsdd2,smb_avahi,usb_storage,docker_deps,proxy,light_apps,geo_full
```

其他机型保持原样，geo 数据仍然不进 rootfs。

## 体积

按设备上现有数据实测（gzip 估算上界）：

```text
geoip.dat    15.7 MB → 3.4 MB
geosite.dat  10.9 MB → 3.6 MB
合计         26.6 MB → 约 7 MB
```

squashfs 用 xz 时会更小，镜像预计从 60 MB 增至 67 MB 左右，分区仍有约
20 MB 余量。

## 仍未内置的部分

`chnlist`、`gfwlist`、`chnroute`、`chnroute6` 没有对应的软件包，由
PassWall 的 `rule_update.lua` 从 jsdelivr / ispip.clang.cn 下载到
`/usr/share/passwall/rules`（overlay，共约 1.5 MB）。要一起内置需要另外
做一个包或者在 base-files 里预置文件，本次没有改。

## 生效方式

下次重编 AX6600 时生效，本次不单独重编。构建时会从 GitHub 下载 geo 数据
（`v2ray/geoip` 与 `domain-list-community` 的 release），GitHub 不通时需要
提前放到 `libwrt/dl/`。
