# 2026-10-30 19:50 — BE12 Pro 精简 app：移除 istore / xray-core

## 背景

SSH 检查 `192.168.2.153`（Tenda BE12 Pro）发现：

```text
UBI total:       87.1 MiB
rootfs:          72.0 MiB
rootfs_data:     11.8 MiB
overlay:         9.1 MiB
overlay free:    5.2 MiB
UBI available:   0
```

主要体积来源：

- `sing-box`：约 54 MiB
- `xray-core`：约 28 MiB
- `lucky`：约 13 MiB
- `quickstart`：约 11 MiB
- `kmod-mt_wifi7`：约 13 MiB
- `luci-app-istorex`：约 4.8 MiB

`sing-box` 和 `xray-core` 同时存在，是因为 `proxy.config` 选了 sing-box，而 PassWall 默认 `INCLUDE_Xray=y` 又带入了 xray-core。

BE12 Pro 没有 USB，也没有磁盘阵列使用场景，因此不需要为这类设备保留 istore/diskman 等大体积或无关组件。

## 变更

新增 BE12 专用 fragment：

```text
wrt_core/deconfig/fragments/tenda_be12_pro_minimal.config
```

内容：

```text
# CONFIG_PACKAGE_luci-app-istorex is not set
# CONFIG_PACKAGE_luci-app-diskman is not set
# CONFIG_PACKAGE_smartmontools-drivedb is not set
# CONFIG_PACKAGE_luci-app-passwall_INCLUDE_Xray is not set
# CONFIG_PACKAGE_xray-core is not set
CONFIG_PACKAGE_luci-app-passwall_INCLUDE_SingBox=y
```

`tenda_be12_pro_immwrt.ini` 的 fragments 改为：

```text
proxy,tenda_be12_pro_minimal
```

也就是：

- 去掉 LuCI iStoreX 和 quickstart/store 相关依赖
- 去掉 diskman / smartmontools drivedb
- 去掉 PassWall 的 Xray 后端
- PassWall 改用已有的 `sing-box` 后端
- `sing-box` 本身保留

这个 fragment 只作用于 BE12 Pro，其他机型不受影响。

## 预期效果

- 不再安装 `xray-core`（约 28 MiB 安装体积）
- 不再安装 `luci-app-istorex` 及其 quickstart/store 依赖（约 16 MiB）
- 去掉 diskman / smartmontools drivedb
- rootfs 应该明显缩小，`rootfs_data`/overlay 可用空间相应增加

实际 overlay 增加多少取决于 squashfs 压缩率和重新生成 UBI 时的 rootfs 大小；需要重新编译、重新刷入后验证。

## 验证

  - `# CONFIG_PACKAGE_luci-app-passwall_INCLUDE_Xray is not set`
  - `# CONFIG_PACKAGE_xray-core is not set`
  - `CONFIG_PACKAGE_luci-app-passwall_INCLUDE_SingBox=y`
  - `CONFIG_PACKAGE_sing-box=y`
- `./build.sh tenda_be12_pro_immwrt config_preview` 通过
- `bash -n build.sh` 通过
- 尚未重新编译；需要下一次 BE12 构建验证最终的 rootfs/overlay 大小

## 注意

- 现有设备如果只做 sysupgrade，新的 rootfs 会替换旧 rootfs，但 `rootfs_data` 的 UBI 卷大小是否立即扩展取决于 sysupgrade/UBI 行为；最可靠的是重新刷入新镜像并确认 `ubinfo -a` / `df -h /overlay`。
- 如果仍需要 xray 或 istore，可在该设备配置中移除 `tenda_be12_pro_minimal` fragment 后重编。
